Architecture

How It Works

Four-stage pipeline, from raw global news to structured API response.

INGEST

GDELT BigQuery API pulls events and articles. 380K+ sources in 100+ languages. Daily automated pipeline.

→
PROCESS

Geo-resolve to city, deduplicate events, extract entities and themes, rank source credibility across 4 tiers.

→
SCORE

AI evaluation engine with schema enforcement. 12 dimensions scored deterministically. Pydantic-validated output.

→
SERVE

Pre-computed scores cached in Postgres. FastAPI serves sub-50ms JSON responses. Free dashboard + paid API tiers.
